# EleganTech - Toko Smartphone Premium

Website E-Commerce statis bergaya premium yang dirancang untuk menjual perangkat smartphone terkini (fiktif). Dibangun menggunakan HTML, CSS, dan Vanilla JavaScript.

## 🛠️ Fitur Utama
1. **Desain Elegan & Responsif:** Menggunakan perpaduan warna monokrom gelap dengan aksen emas yang berkesan premium. Tampil baik di desktop, tablet, maupun smartphone.
2. **Katalog Produk:** Menampilkan *grid* daftar HP lengkap dengan gambar HD, judul, dan harga.
3. **Pop-up Login System:** Fitur interaktif untuk otentikasi pengguna menggunakan modal/popup tanpa harus memuat ulang halaman.

## 📁 Struktur File
- `index.html` : Rangka utama website.
- `style.css` : File untuk gaya desain (styling).
- `script.js` : Logika interaksi popup login.
- `README.md` : Dokumentasi proyek.

## 🚀 Cara Menjalankan
1. Pastikan semua file berada dalam satu folder yang sama (atau ekstrak file .zip ini).
2. Klik ganda pada file `index.html` untuk membukanya di browser (Chrome, Firefox, Safari, dll).
3. Klik tombol **Login** di sudut kanan atas untuk melihat fitur modal otentikasi berfungsi.
